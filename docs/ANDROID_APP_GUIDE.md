# SoloLedger 순수 Android 전용 앱 설치 및 외부 접속 가이드 (`ANDROID_APP_GUIDE.md`)

본 문서는 `SoloLedger` 순수 안드로이드 앱(`kr.sololedger.mobile`, `Kotlin + Jetpack Compose`)을 스마트폰에 설치하고, **사무실 밖에서도 안전하게 영수증 처리 및 세무사 제출(`SoloLedger_세무증빙_YYYYMM.zip`)**을 수행하는 방법을 안내합니다.

---

## 1. 스마트폰에 앱(`.apk`) 10초 설치 방법

사무실 Wi-Fi에 스마트폰을 연결한 상태에서 아래 주소로 접속하면 USB 케이블 없이 바로 `.apk` 설치 파일이 내려받아집니다.

1. 사무실 PC의 내부 IP 확인 (예: `192.168.0.10`)
2. 스마트폰 Chrome 브라우저 주소창에 입력:
   - `http://<사무실PC_IP>:8000/download/apk`
3. 다운로드된 **`SoloLedger-v1.1.0.apk`** 실행 → *출처를 알 수 없는 앱 설치 허용* 1회 승인 → 설치 완료
   - PC 파일 탐색기에서 직접 옮기실 경우 `dist/SoloLedger-mobile.apk` 파일을 카카오톡 나에게 보내기 또는 USB로 복사해 설치하셔도 됩니다.

---

## 2. 외부(사무실 밖)에서 안전하게 접속 설정하기 (Tailscale 권장)

공유기 포트포워딩이나 구형 `ipTIME NAS II` 외부 노출 없이, 무료 **Tailscale VPN**만 설치하면 가장 안전하게 외부 접속이 가능합니다.

1. **사무실 상시 PC**: [Tailscale Windows 버전](https://tailscale.com/download) 설치 후 구글/마이크로소프트 계정 로그인
2. **Android 스마트폰**: Google Play 스토어에서 **`Tailscale`** 설치 후 **동일한 계정**으로 로그인
3. Tailscale 앱에 표시된 사무실 PC의 전용 IP 확인 (예: `100.85.12.34`)
4. **SoloLedger 앱 실행 → `[⚙️ 설정·보안]` 탭**:
   - **서버 주소**: `http://100.85.12.34:8000` (사내 Wi-Fi 전용으로만 쓰실 경우 `http://192.168.0.x:8000`)
   - **비밀번호 또는 API 키**: `.env`에 설정한 `SOLOLEDGER_ADMIN_PASSWORD` 또는 `SOLOLEDGER_API_KEY` (기본 개발키: `dev-sololedger-secret-key`)
   - **`[🔌 연결 테스트 및 인증 토큰 발급·저장]`** 터치 → 30일 유효 서명 토큰이 발급되어 자동 로그인됩니다.

---

## 3. 앱 주요 업무 흐름

1. **영수증 촬영 · 매입내역 등록 (`[📷 영수증·등록]` 탭)**
   - **`[📷 카메라로 영수증 바로 촬영]`**: 종이 영수증을 찍으면 자동 회전 보정 및 JPEG 압축 후 사무실 서버의 Vision OCR이 상호·금액·사업자번호를 추출해 원장과 매칭합니다.
   - **`[📂 엑셀(.xls/.xlsx) · CSV 파일 업로드]`**: 스마트폰으로 받은 우리카드·홈택스 내역 파일을 바로 대사 반영할 수 있습니다.
2. **원장 분류 · 거래명세서 확인 (`[🧾 원장·명세서]` 탭)**
   - `[⚠️ 미분류·소명필요]` 칩을 눌러 미정리 건만 모아 보고, 전표를 터치해 **신용카드 매출전표 / 다품목 거래명세서**를 확인합니다.
   - 계정과목(`811 복리후생비`, `813 기업업무추진비`, `830 소모품비`, `822 차량유지비` 등)과 참석자·품목을 입력 후 저장하거나 전자 거래명세서를 즉시 발급합니다.
3. **세무사 바로 제출 (`[📦 세무사 제출]` 탭)**
   - 제출할 귀속 연월(`YYYYMM`, 예: `202611`)을 선택하고 **`[📦 세무증빙 ZIP 생성 후 카톡·메일로 바로 보내기]`**를 누릅니다.
   - 사무실 PC가 표준 기장원장 CSV + 정규화 증빙 파일 전체를 `SoloLedger_세무증빙_YYYYMM.zip`으로 압축해 스마트폰으로 전송하고, **즉시 카카오톡·이메일 공유 시트**가 열려 세무사에게 바로 전달할 수 있습니다.
4. **선택 기능 (`[⚙️ 설정·보안]` 탭)**
   - **지문 · 생체인증 잠금**: 외부 분실 대비 앱 실행 시 지문/패턴 잠금을 활성화합니다.
   - **우리WON카드 푸시 자동 수집**: 스위치를 켜고 알림 접근 권한을 허용하면, 우리카드 결제 푸시 발생 시 광고/명세서 알림은 자동 제외하고 실제 승인 건만 원장에 실시간 등록합니다(오프라인 시 앱 내부에 임시 저장 후 재연결 시 자동 전송).
   - **ipTIME NAS II 백업**: `[📊 홈·요약]` 탭의 **`[💾 NAS 백업]`** 버튼을 누르면 사무실 내부망의 `ipTIME NAS II`(`Z:\`)로 DB 스냅샷과 증빙 원본이 안전하게 백업됩니다.
